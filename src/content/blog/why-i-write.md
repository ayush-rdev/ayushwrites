The short version: because it's mine.

The long version involves three reasons, roughly:

1. **Writing forces thinking.** I don't actually know what I think about something until I try to explain it to someone else — even a hypothetical someone.
2. **A place to point at.** When people ask what I'm up to, I can point here instead of summarizing. The blog does the talking.
3. **Small is sustainable.** No engagement metrics to check, no consistency pressure. If I post once a month, great. The internet will still be here.

```bash
# the entire publishing pipeline
$ vim post.md && npm run build && rsync -av dist/ server:
```

There's a kind of freedom in writing for an audience of one (me, later) with the door open.
